# Patches applied to TrinityCore (forever branch)

Applied in name order right after the `git clone` (see the Dockerfile). The build stops if a patch no longer
applies: either it was merged into the branch (delete it) or it needs updating.

| File | What it fixes (found with packet logs of client 1.60.1.70450) |
|---|---|
| `0002-classic-surname-invite-and-names.patch` | For inputs containing "Name Surname", `normalizePlayerName` keeps the character name (first word) for lookups such as add friend, ignore, guild, and mail. The current forever branch already contains its updated `CMSG_PARTY_INVITE` parser. |
| `0003-classic-contact-list-request.patch` | The 1.60 client's `CMSG_SEND_CONTACT_LIST` is 5 bytes: one byte (0) before the flags. Read as a uint32 it gave wrong flags (0x1500) and the server sent an empty friend list every time it was opened, although the friends were stored. |
| `0005-companions-core-hooks.patch` | Hooks for the companion bots ([docs/COMPANIONS.md](../../docs/COMPANIONS.md)): `WorldSession::IsBot()` for sessions without a client (no packets sent, no idle kick on the missing socket, no time sync, `online` flags kept per character), a per-bot update hook in `Player::Update`, `LoginQueryHolder` in a header so a bot can be loaded, `Group::GetTargetIcon` for raid markers, and the module registration in `custom_script_loader.cpp`. Also: a spell whose explicit target left during the cast (a corpse revived while someone resurrects it) fizzles instead of stopping the server on an assertion; `CreatureScaleHooks` lets the module scale creature health when stats are computed (40-player raids tuned for 20), and the three boss scripts that set a fixed health (Razorgore, Kel'Thuzad's adds) apply it too. `Player::GetLootRolls` and `LootRoll::GetItemId` let a bot answer loot rolls. Classic PvP realm rules in `Player::UpdateHostileAreaState`: the 1.60 zones only carry their faction, so on a PvP realm contested and enemy territory flag players (and bots) for PvP. |
| `0006-classic-script-fixes.patch` | Classic instance scripts. Crashes: Dire Maul (Gordok Brute, King Gordok's guards, Alzzin, Kalendris), Baroness Anastari, the AQ40 bug trio and a Feralas sprite darter used their victim without checking it (a victim lost mid-fight stopped the server). Blackrock Spire: the Blackhand Summoners' deaths (SmartAI) are counted, so the rune rooms empty and Pyroguard Emberseer's door opens. Shadowfang Keep: Arugal's four voidwalkers come when Fenrus dies and their deaths open the Sorcerer's Gate; Rethilgore's prisoners speak. Target limits the client data lacks: Gurubashi Axe Thrower's Axe Flurry hits one random enemy a second (it hit everyone within 30 yards: 1250 damage and a stun each, a sure raid wipe), Nefarian's mage call polymorphs the one player the mage casts at (it polymorphed every ally within 100 yards). Ruins of Ahn'Qiraj: General Rajaxx's army comes in waves again (a VMaNGOS DB script the port left out): pulling a pack sets it moving, the next wave charges 5 seconds after the last one falls (or after 3 minutes), each with Rajaxx's yell, and after Colonel Zerran's wave Rajaxx comes himself (his SmartAI keeps him passive and unkillable until then; pulling him sets the army moving); a wipe resets it. |
| `0007-classic-tank-threat.patch` | The 1.60 client data marks tanks with a new aura type, 668 ("IsEffectivelyTank": Defensive Stance, Bear Form, Dire Bear Form, Righteous Fury) that carries no value; the core skipped it, so stances and forms gave no threat bonus at all. It is handled as the classic bonus: +30% threat of every school (Righteous Fury keeps its +60% Holy threat on top). |

The current `forever` branch already includes 360 action-button storage and packet handling, and no longer asks for `WorldSession::IsBot()` in ammo selection (the old `0004` patch), so no local patch is needed for either.
